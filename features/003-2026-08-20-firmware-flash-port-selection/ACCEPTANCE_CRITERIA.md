# Критерии приёмки: выбор COM-порта при прошивке из UI

## UI и актуализация списка

1. **AC-1 (FR-1):** на экране `Update` отображается выпадающий список COM-портов, доступный с клавиатуры и мышью.
2. **AC-2 (FR-2):** список показывает каждый текущий системный COM-порт один раз, сортирует имена регистронезависимо, добавляет доступный Windows friendly name, `Espressif/ESP32` для VID `303A` и auto marker для подтверждённого LumaBloom-порта.
3. **AC-3 (FR-3):** при первом входе на `Update` список заполняется и показывает default selection; каждое последующее раскрытие вызывает новое перечисление системных портов, поэтому подключённый порт появляется без перезапуска приложения.
4. **AC-4 (FR-3):** порт, отключённый после предыдущего раскрытия, отсутствует при следующем раскрытии.
5. **AC-5 (FR-2):** обновление списка не пытается открыть порты и не разрывает активное telemetry-соединение.

## Автоматический и ручной выбор

6. **AC-6 (FR-4):** если вручную порт не выбирался, автоматически обнаруженный доступный LumaBloom-порт выбран по умолчанию.
7. **AC-7 (FR-4):** действующий ручной выбор сохраняется после повторного раскрытия, если порт остался доступен.
8. **AC-8 (FR-4):** после исчезновения вручную выбранного порта приложение выбирает доступный автоматически обнаруженный порт; при его отсутствии переходит в состояние «порт не выбран».
9. **AC-9 (FR-4):** новый auto-detected порт обновляет значение по умолчанию, пока пользователь не установил действующий ручной override.
10. **AC-10 (FR-5):** ручной выбор не изменяет порт runtime-чтения телеметрии и не записывается в `appsettings.json`.

## Запуск прошивки

11. **AC-11 (FR-6):** при выбранном порте и доступном bundled firmware нажатие `Flash firmware` ставит ровно один запрос прошивки с этим портом.
12. **AC-12 (FR-6):** `FirmwareFlashService` передаёт выбранный порт в аргументе `--port` независимо от последующих изменений UI или telemetry-соединения.
13. **AC-13 (FR-6):** ручная прошивка может стартовать в состоянии `WAITING`, если Windows видит выбранный порт и bundled firmware доступен.
14. **AC-14 (FR-7):** если выбранный порт исчез до обработки запроса, `esptool.exe` не запускается, UI обновляет список/выбор и показывает ошибку с именем порта.
15. **AC-15 (FR-8):** активный reader на том же порту закрывается до запуска `esptool.exe`, поэтому приложение не удерживает flash-порт.
16. **AC-16 (FR-8):** reader на другом порту не закрывается только ради освобождения вручную выбранного flash-порта.
17. **AC-17 (FR-8):** после успеха или ошибки приложение запускает обычное auto-discovery, если reader отсутствует/был закрыт; reader другого порта продолжает обычное чтение без принудительного переподключения.
18. **AC-18 (FR-9):** запуск, успешное завершение и ошибка отражают фактически использованный COM-порт в статусе и `Events`.

## Ошибки и конкурентные действия

19. **AC-19 (FR-9):** при отсутствии системных портов показано локализованное состояние «COM-порты не найдены», а прошивка недоступна.
20. **AC-20 (FR-9):** при наличии портов, но отсутствии выбора показано локализованное приглашение выбрать порт, а прошивка недоступна.
21. **AC-21 (FR-9):** во время `BundledFirmwareSnapshot.IsBusy=true` список и кнопка прошивки недоступны; повторные клики не запускают второй `esptool.exe`.
22. **AC-22 (FR-9):** исключение при перечислении портов не завершает приложение, отображается как пользовательская ошибка, и прошивка остаётся недоступной до успешного обновления.
23. **AC-23 (FR-9):** отсутствие bundled firmware или `Tools/esptool.exe` сохраняет существующее безопасное поведение и не запускает прошивку.

## Локализация, доступность и layout

24. **AC-24 (FR-10):** новые подписи, placeholder и сообщения доступны на английском, русском и испанском языках.
25. **AC-25 (FR-10):** имя COM-порта отображается без перевода и искажения.
26. **AC-26 (FR-1, FR-9):** список можно раскрыть, выбрать и подтвердить с клавиатуры; эквивалентный сценарий работает мышью.
27. **AC-27 (FR-9):** при обычном и компактном размере терминала список, firmware status и кнопки не перекрываются во всех трёх языках.

## Совместимость

28. **AC-28:** автообнаружение runtime-порта по `id="lumabloom"` и полю `raw` продолжает работать без ручного выбора.
29. **AC-29:** JSONL-протокол, `connection.baudRate`, `connection.discoveryTimeoutMs` и обработка яркости не изменены.
30. **AC-30:** команда прошивки по-прежнему использует chip `esp32c6`, baud `460800`, offset `0x0` и bundled merged firmware.
31. **AC-31:** изменение не добавляет обязательных полей в `appsettings.json` и не требует миграции пользовательского конфига.

## Автоматизированная проверка

32. **AC-32:** unit-тесты каталога портов проверяют дедупликацию, сортировку, friendly name/Espressif metadata, пустой результат и преобразование исключения в безопасный результат.
33. **AC-33:** unit-тесты runtime state проверяют auto-default, ручной override, сохранение выбора после refresh, fallback при исчезновении порта и snapshot запроса прошивки.
34. **AC-34:** unit-тесты orchestration проверяют прошивку выбранного порта в состояниях connected и `WAITING`, проверку исчезнувшего порта и восстановление auto-discovery.
35. **AC-35:** unit-тест сервиса/построителя команды проверяет, что выбранный порт передан как отдельный аргумент `--port` вместе с неизменными параметрами flash-команды.
36. **AC-36:** из `pc-app/` успешно выполняются:

```powershell
dotnet build brightness-sensor.sln
dotnet test brightness-sensor.sln
```

Новые предупреждения не допускаются без отдельного документированного решения.

## Ручная проверка на Windows и устройстве

1. Запустить portable app с подключённым LumaBloom и подтвердить auto-selected порт.
2. Подключить второй COM-девайс, раскрыть список повторно и подтвердить появление нового порта.
3. Выбрать второй порт, снова раскрыть список и подтвердить сохранение выбора.
4. Отключить выбранный порт, раскрыть список и подтвердить fallback.
5. Запустить приложение без валидной LumaBloom-телеметрии, выбрать видимый порт вручную и запустить прошивку.
6. Прошить автоматически обнаруженный ESP32-C6 и подтвердить успех и повторное подключение телеметрии.
7. Повторить с занятым и исчезнувшим портом; подтвердить безопасную ошибку без завершения приложения.
8. Во время прошивки попытаться повторно открыть список и нажать flash; второй процесс не должен стартовать.
9. Повторить основные действия на `en`, `ru` и `es`, с клавиатуры и мышью.
